# Security policy

Tandem is pre-release software under active development; no version is yet supported for production use.

## Reporting a vulnerability

Please report suspected vulnerabilities privately through GitHub:
**Security tab → "Report a vulnerability"** on this repository
(<https://github.com/hawsen-the-first/tandem/security/advisories/new>).

Do not open a public issue or pull request for a vulnerability.

Helpful details: the affected component or file, steps to reproduce, the impact you expect, and any
suggested fix. We aim to acknowledge reports within 7 days and to keep you informed about the fix.

## Scope notes

Tandem is self-hosted. Operator-owned settings (TLS termination, disk encryption, backups, network
exposure) are described in the self-hosting guide as it is written; reports about misconfiguration of
a deployment are welcome but may be answered with guidance rather than a code change.
